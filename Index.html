Atelier Vidéo Batch

Principe : ce fichier ne contient ni CSS ni JavaScript.
Il utilise uniquement des formulaires HTML natifs pour envoyer vos images et votre prompt à l’API Agnes, qui génère les vidéos en batch.
Chaque image produit une vidéo. Le navigateur affiche ensuite les résultats.

Résultats

Une fois le formulaire envoyé, l’API Agnes renvoie les vidéos générées.
Selon la réponse du serveur, elles peuvent s’afficher directement ci-dessous ou être téléchargeables via des liens.

Note : ce fichier HTML pur ne peut pas afficher dynamiquement les vidéos sans JavaScript. Pour un affichage automatique dans la page, il faut ajouter du JS. En HTML pur, le navigateur affiche la réponse brute de l’API ou télécharge les fichiers.

Mode batch sans limite

Pour envoyer plusieurs images en une seule fois sans JavaScript, utilisez un champ multiple comme ci-dessus. Le navigateur envoie toutes les images dans la même requête.
L’API Agnes les traite séquentiellement et renvoie une liste de vidéos.

Si vous voulez découper le batch en petits lots, créez plusieurs formulaires identiques et envoyez-les l’un après l’autre.

Rappel des paramètres API

  • Endpoint : https://apihub.agnes-ai.com/v1/videos
  • Méthode : POST
  • Modèle : agnes-video-v2.0
  • Champs : api_key, image(s), prompt, num_frames, frame_rate, effect
  • Réponse : URL(s) de vidéo(s) générée(s)
